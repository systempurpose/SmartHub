Questions before you install

Short answers for technicians and shop owners.

Does it work on iPhone?

No. SmartHub is built for Android phones and talks to them over ADB (USB debugging). Some tools, such as Boot Status and USB Drivers, also help with phones that cannot start.

Do I need to root the phone?

No. Most tools work on an unrooted phone. Deep Scan and the photo carver in Data Recovery need a rooted phone.

Why does Windows warn me about the installer?

This is an early alpha and the installer is not code-signed yet, so SmartScreen shows a warning for new, unsigned files. Use More info, then Run anyway only if you downloaded it from this page.

My phone is not detected. What now?

Turn on USB Debugging (tap Build Number 7 times in About Phone), use a data-capable cable, accept the RSA prompt on the phone and install the right USB driver. The app has a built-in wizard and a USB Drivers page for 30+ brands.

Do I need an account?

Sign-up and sign-in happen inside the Windows app. An account is needed for Community features.

Is it legal to use on any phone?

Use repair, recovery and unlock tools only on devices you own or have permission to service.
